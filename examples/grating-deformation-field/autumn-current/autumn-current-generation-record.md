# 《Autumn Current》本次实际使用的完整提示词

以[原始照片](source-photo.jpg)为唯一来源，最终 1086 × 1448，3:4 竖版，上下各 724 像素。上半从原照保留完整人物、花束和邻近树叶，略裁顶部树冠与极少底边，将这段原片等比置于中央。左右补景后，中央复用原片裁幅，左右交界做轻微羽化。下半按同一张原照生成线场。

## 上半摄影扩景

将[横幅扩景参考](working/outpaint-guide.png)作为输入。

```text
请将附件中左右带白栏的 3:2 图像补成一张同尺寸、满幅连续的真实摄影。白栏之外的中央约 67.6% 是原始照片的真实取景，原样保留中央图像的像素、位置、比例、焦距、颗粒、曝光与自然光影，尤其禁止改动人物的身份、侧身低头、手与橙色花束、伸向画面右方的另一只手、深棕花纹外套、双腿和黑袜、鞋、原有落叶和上方逆光黄叶。只填充左右纯白栏里的环境。左侧从原片边缘顺着秋金色树叶、树荫和左下浅金草地自然继续，右侧从原边缘继续深蓝绿树林的虚焦暗部、浅光斑和低处同高度的地面。保持所有衔接处的颜色、景深、地面方向和亮度一致，过渡无接缝。两侧扩景保持安静，不复制原片做镜像，不补入任何人物、花束、显眼新物件、文字、相框、均匀虚化填边或滤镜。仅输出这一张摄影横幅。
```

## 下半光栅形变设计

将[原始照片](source-photo.jpg)作为唯一参考。

```text
以上传的金色秋叶下捧橙花的摄影为唯一图像参考，为“光栅形变场域”双区海报制作下半区。只输出单张横向 3:2 排版成品，暖象牙白底，细密清晰的多色线场。上半的原照将另行合成，此图禁止摄影粘贴、画中画与上下分区。

选定横向为基本方向。使用 continuous fine parallel grating-line field with controlled smooth deformation，让同一片密集的细线从图形左边连续贯穿到右边。使用 extremely fine, crisp, smooth, unbroken curves with consistent stroke weight，线宽始终一致，线间距在主体附近平滑压缩、扩张，远离形变区时自然回到笔直平行且均匀的间距。每根线在横向上始终前进，曲率连续，无回折、突然断开、分叉、交叉、锯齿或粘结粗线。整幅看起来是一片连续的光栅，起伏完全由线条位置和疏密暗示。使用 a hidden sculptural form emerging through compression, expansion, bending and negative space，线条绕开腋下、花束与伸出的前臂之间的空隙以及两腿间的细隙，保持曲线穿过或平滑绕行，绝不镂空剪断、勾一圈轮廓或填入任何实色人形。

用少数几个柔和的大形变把原片概括出来。画面中间安排从头顶到鞋的完整单人线场形体，保留原片身体朝画面右方、头稍俯、橙花抱在胸前、另一手臂向右伸出的姿态。头肩连成一个较窄形变，外套和伸出的手臂组成相互连贯的宽形变，下方双腿是两道平缓拉长的压缩与舒展。人物居中略偏右，左上出现同源树冠下垂的长弧形变，右后留成较安静的林地平行线，近地只做一组宽而低的水平起伏。让受控形变的整体视觉范围约占图形区 70–80%；舍掉单个树叶、衣服图案、花瓣、五官和手指等碎细节，避免随机涟漪。

使用 source-mapped multicolor line field 与 continuous curves with spatially varying color sampled from the source image。颜色由线条自身承担，同一根线跨过景物对应空间时平滑改色。上方尤其左上悬垂树冠用明亮金黄与浅赭金，树冠空隙用低对比暖米色；人物后方中部与右侧的树荫用深蓝绿与暗青松绿；中部人物的发和黑袜用炭褐，外套用少量铜棕与深栗色，脸缘、手和双腿用柔和浅暖肤色，胸前花束形成一处集中的橙赭与金橙短线区；底部日照草地用淡稻草金。保留原照暖金和冷绿的对照，也保留棕色人形与橙花之间的明度差。相邻色区的改变不改变线宽，不截断曲线。不得铺彩色背景、使用单色墨线、按行分配彩虹色、照相网点或用实色填块补图。

横幅四周留少量安静的暖白空间。在下缘线场之外作两个微小、克制、可读的现代无衬线排版块，左下准确写“Autumn Current”，右下准确写“Late Sun”。深青褐细字，字距微疏。除此之外禁止数字、地名、年份、编号、标志、水印和任何文字。排除三维线框和建模、发光扫描线、霓虹、点描、蚀刻交叉排线、满纸噪点、装饰同心圆、玻璃折射、边框、锐利折线和独立人物描边。
```
