# 拼豆工艺插画 `fuse-bead-craft`

## 可直接使用的提示词

```text
用上传的照片作为唯一图源，为每张照片独立制作一张 3:4 竖版「拼豆工艺插画」海报。沿水平中线严格等分，上下同宽、同高，各占总高度的 50%。两区直接相接，不加分隔条、间隙、海报外框或水印。全幅不新增文字。

上半呈现原照片。保留主体身份、构造、比例、姿态、原有构图关系、真实材质、自然光影和色彩氛围。仅做轻微、克制的艺术杂志感摄影调色。等比适配画幅，优先保留主体和关键环境关系，必要时可自然延展已有背景。禁止拉伸、扭曲、重绘或替换主体，禁止增加无关景物。原照本身的文字可保留。

下半将同一张照片做成一件实体热熔拼豆作品（Perler / fuse bead）。保留主体最有辨识度的轮廓、姿态、朝向和构图关系。人物或动物的眼睛、鼻、口等特征按原照的位置关系，简化为少量关键色珠。建筑、器物或风景用轮廓转折、比例和相对位置保留识别线索。保留两至四处能把它和原照对应起来的细节，例如表盘的圆环与指针、不同帆面的交界、家具的相对位置与轮廓。只省去与识别无关的零碎背景。

采用比粗颗粒版本更细密的统一网格，在接近相同占幅下增加颗粒数量，通常约 350–550 颗，外圈白豆计入。按原照复杂度调节，让主体的关键结构有足够格位。每颗为大小一致、热熔后略呈圆角方形的塑料珠，按整齐的横竖网格紧密排列、轻微熔合。珠与珠的单元边界仍可辨，每颗珠的正中央都保留一个可见的细小热熔微孔。外轮廓依网格逐格转折，形成清楚的锯齿阶梯。沿作品外形用同规格白色拼豆做一圈连续的单颗宽包边，白豆也有可见微孔。白边跟随阶梯轮廓，不围成海报外框。

从照片提取有辨识度的主色、明暗与少量点色，每颗珠只用一种纯色，靠相邻色珠的明暗与色相差塑造形态。禁止渐变、水彩晕染、柔焦混色和数字像素滤镜。材质是哑光塑料，热熔后的珠面微微隆起，以柔和漫反射、孔内细阴影和极浅的贴地阴影体现实体厚度。色彩分区保持平整清晰，避免强反光、厚重浮雕和高大的积木结构。

将作品放在干净、均匀的浅色背景上，可用暖白、浅米或淡灰。以带白豆外圈的整件作品为一组，整体视觉占幅约为下半画面的四分之一，周围保留连续的大面积留白。用近正俯视的角度呈现，保持网格和微孔清楚，按主体重心居中或略作偏移。下半不加新增文字、散珠、工具、底板格线、贴纸描边、珠绣、马赛克瓷砖或装饰元素。
```

## 按图应用

- 先锁定原照的比例、姿态和可辨识的局部，再规划细密排珠。在人物眼鼻、器件接合、家具轮廓等关键位置保留足够的色珠分区。需要稳定颗粒数和轮廓时，先画同源排珠参考，再按参考将格位一一转换为实体拼豆。
- 缩小查看，确认含白边的作品约占下半四分之一，背景有连续留白。放大核对珠子大小、网格、单珠微孔、融接边缘和哑光浅浮雕。并排看原照与拼豆，确认主体和两至四处代表性细节还能对应。
