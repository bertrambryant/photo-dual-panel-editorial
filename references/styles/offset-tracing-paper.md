# 硫酸纸错位叠色 `offset-tracing-paper`

## 可直接使用的提示词

```text
将每张上传的图像独立制作成一张 3:4 竖版「硫酸纸错位叠色」海报。每张海报只用一张源图。画布沿水平中线严格等分，上下各占 50%，两区直接相接。中线不加分隔条、边框、额外画格或标签。纸张肌理与风格化色彩集中在下半。

上半保留源图。若输入为照片，保留主体身份、数量、结构、姿态、朝向、真实材质、自然光影与原有色彩氛围，仅作轻微摄影调色，呈现艺术杂志与设计档案质感。为适配画幅可沿原场景自然延展环境，保持主体原比例，避免拉伸、扭曲、镜像或改变主体。若输入本身是插画，上半按原样呈现，保留原有画法和配色。

下半用两张实体纸制作设计手稿。底层是一张厚纸，上面只画 2–3 块平涂色块，颜色取自源图最具辨识度的色区，提亮、净化后保持原有冷暖关系。色块只对应主体大致的颜色分区，采用水粉或丝网油墨的哑光质感，块边保留少量手工误差，底纸上没有描边和内部线稿。上层是一张乳白半透明的硫酸描图纸，使用细针管笔画墨黑或深灰线稿。轮廓与必要结构线集中在这一张纸上。两张纸叠合时，观者才从线条与底色同时读出完整主体。

按题材只保留辨识所需的线索。人物保留数量、姿态、朝向、发型及服装主色，省去五官细节。动物保留物种特征、主要花纹与姿态。建筑保留屋顶走势、主要入口与整体比例。交通工具保留朝向、车轮或船身弧线。风景保留一条关键的地平线、山脊或岸线。省去密集植被、重复窗格、杂乱背景和广告招牌。

让描图纸与底纸略微错开，表现出纸边之间的位移，也让针管笔轮廓和下方色块出现少量错位。掀起一个小角，露出底纸和原本较实的色块，纸下部分的同一色块则因乳白透光而变柔。用真实的薄纸边、轻微皱褶、克制反光和柔和接触阴影表现两层实体纸。线条保持纤细清楚，避免数码透明图层、三维渲染、矢量渐变或满版线稿。

两层纸叠合的组合只占下半宽度约 45%–55%，略偏心摆放。桌面为浅灰或暖白，下半至少留出 50% 的空白。描图纸角落可选用极小的手写「layer 1 / layer 2」或一个短标题，标题语种随主题，也可省略文字。保持版面安静、简洁，有手工设计手稿的质感，避免卡通感或固定海报模板。
```

## 按照片应用

先辨认源图是摄影还是插画，再明确下半最少的识别线索、2–3 种同源颜色、纸层错开方向和翘角位置。出图后核对上下等高、两张实体纸的颜色和线条是否各自独立、叠合后主体是否可辨，以及下半宽度占比、留白和文字是否符合规范。
