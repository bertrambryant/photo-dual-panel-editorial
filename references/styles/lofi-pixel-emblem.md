# 低保真像素徽记 `lofi-pixel-emblem`

## 可直接使用的提示词

```text
将上传的单张照片制作成一张 3:4 竖版双联海报，水平中线上下等高。上半直接保留原摄影，等比裁取能说明主体及其关系的横幅，保留自然光色，无新增文字。

下半制作一件低保真像素艺术残片。先从照片里找出一个有情绪的矛盾，例如重量和退缩、聚集和缺席、明亮和迟疑。选一种可见的主体姿态或物件结构做主形，再留一两处能指向这张照片的线索。让情绪决定一次有意义的变形：影子可以比人更沉，重复的物件可以逐渐缺席，一束光可以从墙面的缺口穿过。依照本图选择合适的动作。省略透视全景、完整背景和次要物件的细节，让人通过形状之间的关系认出来源。

把主形做得足以读出细节，略微偏离中心。以不规则的边缘结束画面，让背景直接从主形的缺口、断处或间隔穿过去。在关系最有张力的一侧留出一块连续空场，另一侧可以密一些。留白的形状由本图决定，避免四边等宽、整齐的矩形取景框，以及悬在中央的小图标。

使用原生低分辨率栅格：深色块承担重量，边缘用有疏密的像素阶梯，半影或快要消失的地方才出现成簇抖动、漏色或短残影。选少量源图色，允许压暗、抽离或让一处颜色格外醒目。可在有意义的位置借用一处复古 GUI 残片、选区断角或局部数字噪点，使它像留在旧屏幕上的操作痕迹；其余区域保持安静。保留 post-internet lo-fi conceptual art 的冷感与手工栅格的生涩。默认无文字。避免复刻照片构图、全幅像素滤镜、均匀噪声、完整模拟窗口、商业图标与水印。
```

## 按照片应用

为每张照片具体写出留下的主形、唤起场景的一两处线索、情绪如何通过变形与留白显现。将选定的像素处理写进同一份提示词。若使用界面残片，让它参与已有关系。
