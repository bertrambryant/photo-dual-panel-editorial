# 霓虹晕染极简象征 `neon-diffusion-symbol`

## 可直接使用的提示词

```text
以上传的图片为唯一来源，制作一张 3:4 竖版「霓虹晕染极简象征」海报。每张源图单独输出一张，沿水平中线严格等分，上下各占总高度 50%，无边框、间隔、分割条或多图拼贴。

上半铺满原照，保留主体身份、结构、比例、姿态、真实质感、自然光影和原有色彩氛围，仅做轻微、克制的摄影调色，呈现艺术杂志与展览摄影质感。优先等比适配，只裁外围冗余内容，必要时自然延展背景。不得拉伸、扭曲、重绘或替换主体，不将下半的霓虹色带入上半。上半无可读文字。若原照已有可读文字，仅用周围原有材质局部淡化字形，保留承载文字的物件、表面和结构。

下半从原照挑出最有识别力的主体轮廓、姿态或空间关系，归纳为一个圆钝、近似剪影的符号。用少量连贯色块建立外轮廓，内部只留一两处辨识所需的负形或转折。符号集中在下半中央或略偏下，约占下半画面面积的 1/4 至 1/3，四周留出充足空场。删除毛发、皮肤、褶皱、器物细节、清晰五官、密集纹理与写实阴影。下半只保留一个视觉焦点。

用深蓝、钴蓝、青蓝建立主体剪影，以暖黄、橙红、珊瑚粉形成中央暖色光场。低对比的蓝色或浅暖色背景从中央向四周缓慢过渡。用柔焦喷绘和宽阔的径向渐变叠染，让轮廓从深浅与冷暖的连续过渡中自然显现。边缘有轻微失焦、叠色和印刷般的柔性扩散，保留足够的轮廓辨识度。颗粒极轻，渐变层次仍然清晰。避免整块平涂、黑描边、锐利矢量切面、霓虹灯管、局部刺眼高光和强投影。

保持平面、朦胧发光、低信息量与克制留白。下半默认无文字，如明确要求文字，仅保留一处很短的小字。禁止大标题、长文字、写实摄影质感、3D、金属反光、复杂环境、贴纸、满版装饰和密集细节。只输出一张完成的海报。
```

## 按图应用

- 先找原图最易识别的外轮廓、姿态或负形。有多个关联物体时，只保留辨识主体所必需的接触或遮挡，并归纳为一个符号。风景可提取特征最鲜明的山脊、岸线或建筑轮廓。
- 明确符号保留哪一两处线索，以及暖光聚集在符号内部或邻接背景的哪个位置。保持暖色光场和蓝色剪影共享同一视觉重心。
- 画面检查以缩略图为准。形体应仍可辨，柔边、色彩扩散与空场应让符号突出，不能被颗粒、实体细节或背景物件盖过。
