# 字符网点旅行拼贴 `ascii-halftone-travel-collage`

## 可直接使用的提示词

```text
请将每一张上传的肖像照片分别制作成一张独立的「字符网点旅行拼贴」编辑海报。每张只用对应的一张原始肖像作为图源，独立输出一张 3:4 竖版作品。上下两区以干净、平直的水平边界相接，高度大致均衡，默认各占一半。确有必要时，为保留脸、手与关键物件，可小幅调整分界高度。禁止用拉伸、扭曲或移动人物来适配布局。撕边与印刷效果只出现在下半区内部。

上半呈现满版的原始肖像摄影，保留人物身份、五官、表情、发型、姿态、手部与动作、服装层次、原有随身物件、环境结构、自然光影和色彩气质。优先等比裁去无关外围，必要时只自然延展已有环境背景。只做轻微摄影调色和极薄胶片颗粒，保留真实肤质与织物纹理，不重绘主体，不新增排版文字。

下半铺暖灰色旧纸，用同一张照片里的真实摄影切片、等宽 ASCII 字符和黑色复印网点重构同一人物。脸部及其与发型相连的辨识轮廓使用连贯、清楚的摄影切片。手部与原照中最能说明动作的一件物件保留真实结构及接触关系。保留原照已有的耳机、书本或设备等辨识线索，突出一件即可。按原图可见内容取舍，避免补造画面没有的肢体、道具和场景。撕裂切边有白色纸纤维，局部呈现旧纸污迹、轻微套印错位及少量裁切线，裁切痕迹保持在拼贴周围。

把部分衣料褶皱、阴影或环境边缘逐步转为等宽 ASCII 符号、黑色复印网点与断裂的印刷颗粒。字符以少量可辨的标点和符号组织明暗，在暗部渐密，向亮部和未印纸面渐疏。网点沿局部真实明暗分布，可见复印墨点、掉粉和断墨。摄影、字符与网点之间有局部交错，人物的眼睛、五官、手部和关键物件保持清楚。旧纸、黑墨、压低饱和度的原照色彩与一处克制的小红色校准条组成色盘，摄影切片保留可辨的同源色彩。

下半人物占下半画面宽度约 60%–88%，按原照适度重取景，强调姿态或人与物的接触关系。保留约 22%–38% 的连续未印刷纸面，留白有明确落点。只排三项可读文字。依据照片可见内容拟一个简短的等宽英文主标题，搭配固定字段「REC. STUDY 01」及一句简短、具体的英文观察。三项使用等宽排版，在留白或干净边缘集中排列，避开脸、手及关键物件。ASCII 纹理与正文有清楚的间隔，符号只用于组织图像明暗，文字不包含未经证实的姓名、地点、日期或设备参数。

整体应有早期数字排印、模拟复印与旅行档案的克制气质。避免全黑电脑界面、密集代码、赛博朋克霓虹、满幅均匀字符、遮住面部、完全单色化、随机文化符号、伪参数、乱码、作者名、品牌标志、二维码或水印。每张照片只输出一张完整海报。
```

## 按图应用

- 出图前从肖像找出最可辨识的面部、手部动作和一件同源物件，确定保护区域、字符渐疏的方向和纸白位置。未出现的手部、设备或道具不补造。
- 先拟好英文标题和观察句，再逐字写入生成提示词，并保留固定字段「REC. STUDY 01」。校对时放大检查印纹，确认 ASCII 只承担明暗与边缘转译，校准红只出现一处。
