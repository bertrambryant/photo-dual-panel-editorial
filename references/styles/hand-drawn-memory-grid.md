# 手绘九格记忆清单 `hand-drawn-memory-grid`

## 可直接使用的提示词

```text
以这张真实照片为唯一图源，制作一张 3:4 竖版「手绘九格记忆清单」编辑海报。每张照片独立制作一张。画布沿水平中线严格等分，上下同宽、等高，各占总高度 50%，直接相接。无分隔条、间隙、海报外框、多图拼贴或水印。

上半使用原摄影像，保留主体身份、五官、体型、姿态、结构、服装、随身物件、真实材料纹理与原有光源色温。仅做克制的杂志感摄影调色，轻增对比、柔化高光、保留暗部细节，可带低饱和胶片观感与极轻细颗粒。为适配画幅，等比取景，优先保住主体与环境的关键关系；必要时沿画面外围自然延展已有背景。禁止拉伸、扭曲、换脸、重绘主体、增加无关景物、强 HDR 或厚重滤镜。上半保留原照自带文字，禁止新增排版。

下半把同一张照片做成一页「记忆清单」。按直观辨识度选恰好 9 个各不相同、能回指原照的图形单元。优先提取主体的概括剪影和关键局部，其次按实景选取服饰、随身物件、植物、食物、交通工具、建筑、姿态、光线、情绪和小记忆点。只选有原照依据的内容。若题材单一，可从局部轮廓、纹理、动作或光影选择不同切入点。情绪符号也要能通过原照的可见线索解释，不添加画面没有依据的人、物、地点或情节。按 3 行 3 列组织九个单元。每个单元是一幅手绘小图案，可按需写极少量可读的手写短注。

采用 Naïve hand-drawn doodle 的稚拙手绘。用细黑线勾出简洁形体，轮廓轻微抖动、粗细不均，局部可以不完全闭合。蜡笔和彩铅填色保留纸纹、露白颗粒与毛糙边缘，局部可用小面积纯色平涂。图形关系用平面色块、点色和线条建立，不模拟真实光影。下半以暖白或浅纸色为底，从原照选 3–4 个主色用于填色与点色；黑线和纸白只作笔墨与纸底，不另添无关彩色。上下色彩呼应，呈现独立出版物的对开页质感。

使用隐性的松散 3×3 网格。以各单元的标称落点为基准，沿横纵方向在该单元对应尺寸的 ±8% 内微调，图案尺寸可略有变化，旋转控制在 ±6° 内。仍要读得出三行三列。需要辅助线时仅保留极淡、局部的 HB 铅笔底稿线，不画整齐的格框。下半留白不少于 35%，四边各留 8% 的安全边距。相邻图案、标题、附注和脚注均留有间隔，彼此不触碰。

在下半上方写一个 2–5 词、从原照提炼且确实可读的手写标题，附近配 1–3 个短波浪线或小星点。页脚用一句极小、简短且有画面依据的手写说明，字高约为标题的四分之一。字形保留手写的小变化，避免花体难读、印刷体、电脑字体与乱码。波浪线、星点和文字均不计入九个图形单元。上下两处文字层级安静，留九个图形作主要内容。

禁止写实插画、3D 渲染、矢量图标、贴纸粗边、精细线稿、完整描摹原照、机械工整网格、信息图表、乱码、签名、水印、油画或水彩晕染、拥挤贴边和改写上半主体。只输出一张完成的海报。
```

## 按图应用

- 出图前按行列写出九个单元各自对应的原照依据。题材不含某类物件时，用其他可见局部补足。为标题和脚注提前拟好确切文字，按用户指定语种执行。
- 缩看时检查恰好三行三列、图形之间清楚留白、标题在上且脚注在下，装饰不读成新单元。放大核对抖动细黑线、未填满的彩铅蜡笔质感和文字的可读性。
