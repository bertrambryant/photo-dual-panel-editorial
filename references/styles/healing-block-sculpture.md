# 治愈系积木雕塑 `healing-block-sculpture`

## 可直接使用的提示词

```text
将每张上传的照片分别制作成一张独立的 3:4 竖版艺术海报。每张海报只使用一张源照片。沿水平中线严格等分，上下各占 50%，分界清晰。

上半使用对应原照，保留主体身份、结构、比例、姿态、动作、服装、配饰、物体关系、透视、真实材质、景深、自然光影和原有色彩氛围。按原比例裁取有意义的画面，优先保留完整主体和关键关系，必要时适度延展原有环境背景。仅作轻微摄影调色，呈现独立艺术杂志与展览摄影的质感。禁止拉伸、扭曲、重绘主体或新增无关物件。新增排版留在下半。

下半仅以同一张照片为依据，将场景重构为具有三维或等距空间感的「治愈系积木雕塑」。先识别主体最具辨识度的轮廓、姿态、动作与叙事关系，再从主轴、曲线、体量比例、穿插遮挡和负空间中提炼关键结构。用圆润、简洁、有触感的模块重新组织，保留一眼可辨的特征与关系，省去琐碎细节。

依据每张照片的重心与主体朝向，自适应安排模块的位置、大小、裁切、疏密和留白。按需要使用大小体块、高低错层、前后穿插、自然错位、叠放、嵌套、局部悬浮或拼接，形成连贯的空间节奏与当代艺术玩具般的雕塑感。避免规则拆件阵列、简单像素化、品牌积木式颗粒、卡扣复制和固定构图模板。

从原照提取最有辨识度的主色、冷暖关系、明度层级与少量关键点色。沿用原有色相，适度提亮，柔化刺眼反差并去除浑浊杂色。用主色面积、辅助色层次、同源深浅和少量鲜活点色组织明快、柔和而通透的色彩。避免套用固定色卡或加入与原图无关的颜色。

模块表面细腻哑光，具有柔和漫反射和轻微纸浆、木质、粉蜡或柔性材料触感。用圆润边角、轻柔阴影和细微表面肌理表现体量。避免塑料高光、金属反射、厚重渲染或廉价玩具质感。

在下半根据照片的光影、动作、空间、情绪或象征意义拟一个 2–5 个词的英文标题，配少量状态词、方向词、编号或微型注释。有可靠依据时可标地点，不排年份。以轻盈编辑排版沿模块边缘、体块缝隙、视觉轴线或负空间放置文字，允许与体块局部穿插、遮挡或对齐，同时保持标题可读，主体清楚。整体温柔、轻盈、安静、精致，带有克制的童趣与想象力。
```

## 按照片应用

先指出具体要保留的主形、动作或物体关系，再确定哪些部分用圆润模块重组。构图、材质、色盘和排版均随照片决定。出图后核对同源辨识度、模块的空间穿插、光泽与投影、原照取色，以及下半标题是否为 2–5 词且未排年份。
