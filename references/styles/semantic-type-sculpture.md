# 语义字体雕塑 `semantic-type-sculpture`

## 可直接使用的提示词

```text
将每张上传的真实照片分别制作成一张独立的 3:4 竖版「语义字体雕塑」海报，适用于任何摄影主体。每张海报仅使用一张源照片，沿水平中线严格等分，上下各占 50%，满版直接衔接。画面无外框、卡片或过渡带，所有新增图文都位于下半区。

上半直接使用原照，保留主体身份、数量、轮廓、五官、姿态、动作、材质、构图、透视、背景、原色和自然光影。保持原比例，让照片铺满顶部、左右边缘及水平中线。只允许轻微摄影调色与沿原场景自然延展背景。禁止裁掉关键主体、重绘主体、新增物体或添加文字。

下半以同一场景、同一取景为摄影底图，保留主体的位置、姿态、比例与空间关系。从主体的主要承重面、体量或代表性轮廓上选择一块连续的区域，例如建筑的相邻立面、车身的大面或成组岩峰的中部与侧翼。默认移除约占完整主体可见面积 45%–60% 的摄影实体。面积以完整主体或有明确主次关系的主体组为基准，避免只计算一块招牌、窗格或单一小部位，使照片中的同源背景从缺口和字间空隙显露。用与照片主题相关的英文单词、短句和字母在缺口合成新的实体，让字形笔画本身补足失去的轮廓和体量。保留主体的关键识别特征、支撑点、接触和遮挡关系。禁止在完整未移除的主体表面直接叠字。

让字体随原形体的曲率和透视塑形。用字号、粗细、疏密、弯曲、旋转、层叠和局部遮挡建立前后关系，保留字间可见的原场景。以少量准确可读的巨型核心词构成主要体量，在缩略图中也能看清。使用有重量的主笔画、大字孔和清楚字距，搭配 2–3 种协调字形，可选高对比衬线、压缩无衬线或优雅斜体。字形颜色取自原图主色系，可借自然受光面和阴影提高字形与透景的明度差。背景保持摄影质感，仅可轻微柔化。避免塑料质感的立体字、霓虹、厚重阴影和乱码。

下半采用非对称瑞士实验编辑网格，组织五级视觉层次。字体雕塑是第一焦点，其次是清晰且显著小于主体字形的英文艺术标题、1–2 句与画面有关的诗意说明、微型档案编号和少量定位符号。可从超细线、圆点、十字定位符、微型箭头、竖排字与简洁几何符号中择用。顺着主体朝向与现有留白排布，保持文字可读、空间舒展，避免压住主体的关键轮廓。

输出前核对画幅为 3:4、上下严格等高、上半满版且无新增排版。下半可辨认出同一场景、真实的缺口、由字形补足的轮廓、成立的透视与前后关系。标题、说明及符号均留在下半。禁止另起场景、全幅插画、随机文字堆砌或右下角原图缩略图。
```

## 按照片应用

根据照片明确需要保护的识别点、移除的局部与面积、缺口中应显露的原场景、字形如何顺着形体和遮挡补足，以及准确的雕塑用词、英文标题、说明和编号。出图后在整张下半及缩略图尺度检查转绘面积与文字能否一眼辨认，再核对缺口透景和原形体是否连贯、上半原照与分界线，以及核心单词和编辑文字是否准确。
