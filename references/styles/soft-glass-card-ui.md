# 柔光玻璃拟态沉浸式卡片 UI `soft-glass-card-ui`

## 可直接使用的提示词

```text
以上传的图片为唯一来源，为每张源图单独制作一张 3:4 竖版「柔光玻璃拟态沉浸式卡片 UI」海报。沿正中央的水平线将画面严格等分，上下各占总高度 50%，直接衔接，无间隔、分隔条、外框或多源拼贴。

上半满版保留原照的主体身份、结构、比例、姿态、真实质感、自然光影和色彩氛围。仅允许轻微摄影调色，保持艺术杂志与展览图像质感。等比适配，优先裁去外围冗余内容，必要时自然延展原环境。禁止拉伸、扭曲、重绘或更换主体。上半无可读文字。原照已有可读字形时，只在原位用相邻材质淡化字形，保留其承载物和原场景。玻璃拟态和 UI 元素仅出现在下半。

下半使用同一照片所对应的摄影式空间作满版背景，保留真实光向、空间纵深和同源环境线索。用浅景深、柔焦和低对比使背景退居次层。画面只设一张半透明圆角面板，水平和垂直均居中，是唯一视觉焦点。面板外沿宽度约占下半宽度的 40%，高度约占下半高度的 40%。以 1086 × 1448 像素海报为例，下半高 724 像素，卡片取整为 434 × 290 像素。面板上下留白均等，左右留白均衡。背景保持连贯，面板外不放其他图文。

面板内部严格划为三段，固定一组连贯的内边距。顶部放一条简洁的胶囊形搜索框及少量圆形操作按钮。中部为圆角摄影窗口，占卡片高度约 50%，展示同一源图最能辨识主体的取景，保留真实光影、自然景深与细腻表面。底部用左对齐的现代白色无衬线字放一个简短主信息、少量小号状态文字与一个克制的行动按钮。文字可从照片的主题或动作提炼，使用短标签，不虚构地点、时间或数据。搜索、操作和状态图标只用少量白色细线，留足间距。辅助信息限于底部，不添加卡片外排版、长文或大标题。

外层面板与内部控件统一采用高透雾面玻璃，使用冷白半透明填充、轻微磨砂、局部环境色渗透和克制折射。透过面板仍能辨出背景的明暗和色彩过渡。外沿与控件使用极细白色高光和微弱外发光，连续大圆角，边界清楚柔和。下半整体以低饱和雾蓝、灰青、冷白为主，少量柔和暖金高光，摄影窗口细节仍可读。禁止不透明实色卡片、厚重阴影、黑描边、强霓虹、高饱和、复杂渐变、金属或塑料质感、密集图标、装饰性边框、贴纸、邮戳、额外标题与拥挤信息。只输出一张完成的平面海报。
```

## 按图应用

- 从原照选一处辨识度高、适合横向窗口的主体取景。满版背景保留同源环境的光线与纵深，控制背景焦点，让最清晰的主体信息集中在窗口。
- 先定面板外沿尺度与上下等量留白，再排顶部搜索操作、中部图像、底部信息。信息压缩成少量短标签，避免为提高可读性扩大卡片或将内容移到卡片外。
- 核对成品中面板冷白透底、极细边缘高光、折射和背景虚化是否同时可见。中部摄影窗口占卡片高度约一半，面板的三段层级在缩略图上仍应清楚。
