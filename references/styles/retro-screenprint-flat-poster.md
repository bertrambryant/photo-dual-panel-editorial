# 复古丝网平涂海报 `retro-screenprint-flat-poster`

## 可直接使用的提示词

```text
把每张上传照片分别制作成一张 3:4 竖版二分构图海报，每张成品只用对应的一张参考照片。沿水平中线严格等分，上下各占总高度 50%，两区直接相接，无边框、隔条或跨区元素。

上半以原照等比取景并铺满，保留主体身份、结构、姿态、真实质感、自然光影、原有色彩氛围和关键空间关系。只做轻微杂志式调色，必要时仅沿原有环境自然延展背景。禁止拉伸、扭曲、移动、替换或重绘主体。上半无文字。若原照有可辨字样，只在原处清理字形并保留承载表面的结构、材质和光影。

下半将同一张照片转绘成复古丝网印刷风格的平面插画。先从照片中提取主体的标志性大轮廓、前后层次及少量识别标记，优先保留能认出原主题的核心语义。将形体压缩为少量圆润、简洁的大块面。以黑色或原照深色、中等粗细的连续线建立主轮廓，笔压与线宽仅有轻微手工不均；内部只用少量分割线、点或短线概括关键细节。把真实材质、表面细节、写实透视和复杂背景归纳成平面色块与遮挡关系，保留必要的空间层次。

下半用干净的白色满版作底。左侧保留一块连贯、宽阔的文字留白区，可从下半宽度约 29%–32% 取位；右侧是开放的插画范围，无独立画框。主体的视觉重心偏右并向下展开，在底部用连续横向的叠层轮廓收束和承托。承托带从源图的地面、水面、台面、前景、底缘或主体本身层次提炼，以少量横向块面或轮廓彼此搭接，保留上下关系。它主要留在插画范围内，左侧收住，确保文字区仍是一片连续白地。适度扩大并上移右侧主体，以上方白边约下半区高度的 10%–23%、底部白边约 7%–10% 取位，右侧留窄白边。具体高度随题材调整。留白集中在左侧文字区及外缘，收紧中线到插画之间的大块空白。无对应景物时沿用主体底缘做抽象承托，禁止凭空添加地平线、山体、太阳、月亮、圆形装饰、人物或建筑。

从原照片提取主色、辅色和背景中性色，以少量互相分明的平涂色块保留它们原来的冷暖、明度、饱和度与主次关系。颜色少而明确，与深色轮廓一起承担识别和节奏。各平涂色面保留可辨识的细小露纸、纤维状印纹、疏密不均的墨粒和轻微手工印边，深灰和深色油墨可略丰富，浅色适度减少。纹理在预览尺寸可见，并服从大色块与清楚的分色边界。墨色内部可有细微的承墨变化，纹理只印在图形内，左侧白地和字体保持干净。禁止渐变、体积光、摄影纹理、写实阴影、独立的粗网点底块、过量颗粒和复杂纹样。

仅在下半左侧排两行简短英文大字与一行小型辅助说明，围绕同一左对齐线。两行英文均使用细长、窄身、轻字重的无衬线字体，字号相对辅助行明显更大，排版占地小，对比克制但清晰可读，整体视觉权重低于插画。文案依据可见主体、动作或场景拟写；两行合起来读得通，辅助说明只用一行短语。禁止扩展成长段落、厚重标题、满版字、乱码、品牌、水印或虚构地点。避免立体渲染、照片式透视、密集细节、装饰性繁复线条、对称信息图、满版填色及无关背景物。
```

## 按图应用

- 先点出最容易辨认的主轮廓、两至三处关键层次和一处印刷细节，再从原图找到底部承托带的来源。人物、动物、器物、建筑、交通与风景均沿用可见关系，端点与层叠方向按原图调整。
- 确定左侧两行英文和辅助行的实际文案再生成。缩小预览时，先看到右侧插画，再读到左侧文字；检查底部轮廓能连成一组，插画上方的白地适度，文字区连贯。缩小到正常预览时，色块里的印刷肌理仍可辨，白地没有散点或无关符号。
