# 诗意复古杂志半调印刷 `poetic-vintage-magazine-halftone`

## 可直接使用的提示词

```text
以我上传的这一张照片为唯一图源，制作一张 3:4 竖版「诗意复古杂志半调印刷」海报。整张画面连续、完整、正视、满版，直接输出印刷画面本身。原图的主体、大字与纸白留白共处于同一构图中。禁止多图拼贴、样机展示、画面外框、上下等分或生硬横向分割。

画面上方约三分之一为干净的暖米白纸色留白。纸面纹理极轻、网点极少。左上放两段与照片相关的简短诗意英文短句，从原图的对象、动作、光线或季节气氛提炼文字。每段只写一句，使用小巧克制的同色系深色打字机字体，保持间距和清晰可读。右上嵌放同一张原图的完整缩略图，图像宽度约为海报画布宽度的 15%–18%。按原比例等比缩小，完整保留原图四边、内容和色彩；不裁切、不调色、不拉伸、不重绘，不叠加 CMYK 网点。只给缩略图外侧加一圈简洁细边框，在图下排一行小字「ORIGINAL」。缩略图、说明、左上诗句和主体各自留出空间，互不重叠。

在画面中部放一个与照片主题呼应的简短大写英文单词，只用这一个词，采用超大字号的高对比衬线字，单行横跨接近整幅画面。字色取自原照有辨识度的色彩，例如花瓣、枝叶、墙面、水体、果实、衣物或器物材质，选择与背后画面反差足够的一色；蓝色仅在原图和可读性支持时使用。单词保持完整轮廓和可读字距。主体只在关键交叠处压住部分笔画，其他主要字形仍能辨认。除这个大写单词、左上两段短句和「ORIGINAL」之外，不加标题、副标题、编号、标语或其他排版文字。

保留照片的真实摄影质感、原有视角、主体身份、姿态、比例与物体相对关系。画面下部延续原生场景，主体从与原照一致的地面、水面、立面、枝干或支撑关系自然向上延伸，从大字局部前方穿过，主体顶端小幅越过字区进入暖米白留白。主体必须始终连接原场景，保留原有受力、接触与空间关系。人物保持自然头颈与肢体，建筑、植物、动物、器物等遵循原有结构，不为跨字而凭空增加物体、延长主体、改变动作或换景。利用原有轮廓、明暗层次、色调和点密度把主摄影自然过渡至纸白；无平直分割线、矩形色块拼接边、抠图白边、悬浮断层或生硬渐变带。

只在大字区域与主摄影画面铺设细密、可辨识的 CMYK 圆形半调网点。青、品红、黄的圆点呈轻微套印偏移，黑版维持影调和细节，偏移只出现在印点尺度。暗部网点更密，高光处更稀，保留原照材质细节及自然光影，避免在缩略图或上方暖白纸面形成明显印点。以圆形半调网点作为唯一附加纹理，不用普通噪点、胶片颗粒、划痕或额外做旧。禁止新增景物、无关装饰、水印、手绘插画、卡通化、主体变形、缩略图裁切或调色、非指定的图文重叠、文字模糊与乱码。只输出一张完整海报。
```

## 按图应用

- 从照片中选一个可由原生场景自然向上延伸的主体，确定它的支撑点、能越过大字的轮廓及可以被遮挡的笔画。选择该图专属的两个英文短句、一个大写单词与一个有足够对比度的原图色。
- 右上缩略图优先直接放置同一原图，以等比缩小实现保真。缩略图外的细框与「ORIGINAL」是独立排版，不属于原图内容。检查主画面与留白的连续性、大字可读性、缩略图完整性及半调在暗部、高光、纸白的密度差。
