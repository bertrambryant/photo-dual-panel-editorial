# 稚拙马克笔涂鸦 `naive-marker-doodle`

只在画风路由确定为 `naive-marker-doodle` 时读取。

## 核心视觉身份

下半部分使用粗头毡尖笔和不透明颜料马克笔，将原图同一场景重绘成疏简、童稚、俏皮的二维编辑插画。大块形体以纸白为主，粗圆彩色轮廓带自然笨拙感，少量不均匀平涂保留露纸与轻微越界笔迹，整体略带失衡和未完成感。

## 必要生成语法

提示词必须同时包含这些决定：

- `naive editorial doodle in broad felt-tip and opaque paint marker`，平面二维、粗笔手绘，不精修为矢量或写实插画；
- 严格 3:4 竖版、上下各占 50%。仅以上传图作为身份、内容、构图与配色来源。上半忠实保留原照主体、姿势、表情、服装、关键物件、取景、原有裁切、拍摄角度、位置关系、光线及整体色彩；整张源图等比例适配，必要时只延展空余背景，不重新裁掉主体或补出原图未见的身体；
- 下半保持相同姿势、朝向、视角、相对位置、裁切边界与关键互动，所有主体和参与互动的关键道具必须保留，数量不变。人物、猫与其他动物仅在源图出现时绘制，绝不因规范举例而新增猫或人；
- 人物及动物轮廓归纳为大块简洁形状，呈俏皮的笨拙感。人物头部相对躯干偏小，避免大头萌化；这是下半区的风格化比例调整，不改变上半照片。依靠发型、服装轮廓、姿态与关键配件保留身份，不改换人物；面部朝向、表情仍应对应原图，眼睛为圆点或圈，鼻子为歪斜短笔画，嘴为一条短线。面部被遮挡或背对镜头时，不凭空补出五官；
- `thick rounded slightly wobbly single-pass marker contours`，从照片选取一种有辨识度的鲜明颜色作为主轮廓色，主轮廓粗于内部笔画，笔迹自然抖动、轻微粗细不均，每段线一笔完成，内部细节极简；不使用纤细整洁的描边或反复素描排线；
- 配色限制为从原图提取的一种主色及 1–2 种点缀色，纸白不计作点缀色。主色优先承担轮廓，点色保留主体和关键物件的主要色彩关系；原图色彩朴素时选其中最有辨识度的颜色，不凭空加荧光色。保留原图可见色彩关系，但不要求逐像素复刻所有颜色；
- `mostly paper-white forms with sparse uneven opaque marker fills`，大部分服装、皮肤高光区域和次要物件留纸白，仅用彩色轮廓勾勒；少量平涂可见马克笔走向、填色不均、小面积露纸空隙和轻微溢出轮廓的色迹。不要把全部人物涂满，不使用透明水彩、渐变或明暗层次；
- 下半背景为细微纹理的暖米白纸面，大量留白。删除环境、地面、墙壁和所有阴影，仅保留支撑动作所必需的道具：如原图人物坐在椅子上，则保留椅子及坐姿接触关系；环境删除不等于删掉承托主体或参与互动的物件。保留主体在原图中的取景角度与位置，不重新摆成另一种构图；
- `no added text or typography`，整张海报不新增标题、编号、注释、边框、标志、水印或用户界面；下半道具上的细小品牌与告示归纳为空白色面，不生成字样。上半忠实保留原片内容，不为执行该禁令而改画原片。交付说明可使用画风名称，不能把它排进海报。

无人物的图片仍遵循同样的粗笔轮廓、纸白、少量点色与无文字规则，不主动添加人物或宠物。

## 与共享规则的优先关系

本风格明确要求粗厚描边和童稚简化，覆盖共享的避免卡通感、厚重描边要求；明确禁止新增画面文字，覆盖共享的英文标题与编号建议。其有限点色规则不继承光栅的沿线逐区域多色映射，也不继承水墨的晕染或纸雕的层间阴影。

## 专属排除项

明确排除：增加或遗漏主体及关键道具、改变姿势或互动、重裁主体、改变拍摄角度或身份、随意改变主要色彩关系、大头萌化、写实效果、精修人体、纤细整洁的轮廓、繁密背景、满涂全部服装与皮肤、明暗层次、水彩晕染、彩色铅笔、蜡笔纹理、渐变、矢量画风、三维效果、日式动画或漫画风、蚀刻排线、光栅线场、分层纸雕、新增文字、边框、标志、水印和 UI 元素。

## 纯度检查

- 上半是否忠实保留原照，主体、关键物件、取景和裁切是否未变；
- 下半主体数量、身份线索、姿势、视角、裁切与互动道具是否对应原图；
- 是否有粗圆、一笔式、略抖且粗细不均的轮廓，主轮廓粗于内部笔画；
- 配色是否来自照片的一种主色加 1–2 种点色，大部分形体是否仍留纸白；
- 平涂是否保留笔触、露纸和轻微越界，同时没有渐变或阴影塑形；
- 是否去除无关环境并保留动作必需道具，背景为大面积暖米白纸面；
- 是否完全没有新增画面文字、编号、边框或标志。
