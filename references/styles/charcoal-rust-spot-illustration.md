# 炭黑锈红干笔小插画 `charcoal-rust-spot-illustration`

## 可直接使用的提示词

```text
将每张上传照片分别制作成一张 3:4 竖版编辑海报。水平中线上下等高。上半保留源照片的主体、结构、姿态、自然光影和色彩氛围，按内容等比取景，可轻微调色；适配画幅时仅自然延展环境。下半使用暖灰白纸、炭黑主墨和少量铁锈红，制作一幅带短句的干笔编辑插画。

围绕原照中最鲜明的主体，选取两三处真正参与叙事的线索：例如动作所依托的结构、能交代距离的远景，或与主体接触的物件。通过原有的方向、大小差、遮挡或接触把它们连成一个场景片段。缩小看仍能认出是原照片里的这个瞬间。删去琐碎明暗与无关陈设，只给主形最重的笔触。

把图与字安排在下半中央区域，视觉重量靠近中心，可随动作轻微偏移，四边均有余量。横向展开的画面，图文组合可先按下半宽约 60%–70%、高约 50%–65% 取景；纵向主体保持比例，用相邻线索自然撑开宽度。留白穿入物件之间，沿视线或动作方向稍多。不要把整组缩到边角，也不要用完整背景框、底板或无关装饰填空。

用粗石墨、蜡笔或蜡质记号笔的侧锋落下几道有重量的炭痕。形体交界可断线、擦淡、错位或露纸。炭黑负责结构与主次，仅在一两处有意义的位置点入铁锈红。保留暖灰白纸纹，不用多色、写实体积或光滑矢量描边。

每张下半必须出现一行能直接读清的编辑短句，语种随主题。短句取自画面里的具体动作、距离或光线，和插画共同表达同一件事。原图已有的招牌字、书脊字不计作这行配文。用小而清楚的轻字重印刷字，将其贴近图形的落笔处、基线或安静间隙；留出阅读距离，不压住主形。只新增这一句，不加编号、边框或菜单式信息区。
```

## 按照片应用

让每份提示词明确写出保留的主形和场景线索、版面重心、锈红落点及最终印出的准确短句。出图后核对成品短句可辨且拼写正确，并查看四边余量与物件间的留白。
