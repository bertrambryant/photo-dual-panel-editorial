# 低清柔焦渐变剪影 `low-fi-soft-gradient-silhouette`

## 可直接使用的提示词

```text
以上传的照片为唯一图源，制作一张 3:4 竖版「低清柔焦渐变剪影」海报。每张照片独立制作一张。沿画布水平中线严格等分，上下同宽、等高，各占总高度的 50%。两区直接衔接，禁止多图拼接、间隙、分隔条、边框和水印。

上半呈现原照，保留主体身份、结构、比例、姿态、真实质感、自然光影与原有色彩氛围。只做轻微、克制的摄影调色，呈现艺术杂志和展览摄影质感。等比适配画幅，必要时自然延展原有背景。禁止拉伸、扭曲、替换或重绘主体。上半无任何文字。原照如有可读文字，仅在字形所在的表面局部清理，保留载体、原有材质和光影。

下半提取原照主体最主要的外部走势和体量关系，将其压缩为一个静止、水平居中的纵向剪影。形体上部收窄、下部自然展开，约占下半画面高度的三分之二至四分之三，获得接近满高的视觉重心。下缘可以自然贴近底边或轻微裁切，左右保留宽阔贯通的暖灰白负形留白。形体只保留最宽泛的外部走势，彻底省略可辨识的内部结构、表面纹理、细部刻画、硬质高光、明确阴影边缘和环境细节。

使用低频、圆钝、略带不对称的软边块面。由大面积连续柔化渐变、失焦、轻微扩散和一点色彩溢出形成边界。色彩在深墨黑、蓝绿色、暗紫红与酸性黄绿之间缓慢连续过渡，形成宽阔、轻鼓起的气囊式渐变，覆盖主体大部分区域。深色集中于中心和下部，酸性黄绿色作为局部外缘和较宽的过渡色域。明度从外缘向内部逐步压暗，色区低反差地相互渗透。整体柔散、低清晰度，近似喷墨或旧屏幕显影。背景维持均匀浅暖灰白，只保留极弱的纸面或扫描颗粒；颜色溢出限于软边附近。

下半只有这一团由原照衍生的形体和安静留白。禁止清晰轮廓线、线描、排线、清晰焦点、锐利描边、尖锐转角、碎裂轮廓、均匀平涂、硬边色块、细碎笔触、复杂纹理、写实摄影细节、立体建模、局部高光、强投影、独立发光斑、额外物件、叙事背景、装饰图标、文字、边框及满版填充。低清感只用于下半的软化与色阶过渡，保持成品的正常输出分辨率。
```

## 按图应用

- 找出原照中最能承载构图的一个主体。多人、多物或宽景只取一个关键外部走势，归纳为上收下展的纵向形体。保留它与原照的轮廓呼应，辨识主要来自上半原照和上下体量的对应。
- 缩小预览，检查是否只有一个居中形体、是否仍有连续的暖灰白留白，以及酸性黄绿色是否形成宽过渡。放大核对有无硬边、残留内部结构、明显颗粒、局部高光或文字。
