# 暖白超现实摄影拼贴 `minimal-surreal-photo-collage`

## 可直接使用的提示词

```text
将上传的每张照片独立制作成一张 3:4 竖版上下双联海报。上下区以干净平直的水平中线相接，高度严格各占 50%，不加分隔白边、外框或跨区元素。同一张照片是原景的唯一参考。

上半保留真实摄影风貌。保留主体身份、轮廓、姿态、材质、自然光影、原有色彩和关键空间关系。优先等比取景，必要时只自然延展已有环境，可作极轻微的曝光或色彩校正。禁止拉伸、替换、移动或重绘主体，不添加文字或新物件。

下半以暖白哑光纸为底，提炼原照中最有辨识度的主体与一个场景意象，用一个清楚的超现实关系组成单一摄影蒙太奇。保留足以识别原照的轮廓、姿态、结构或表面信息。选择一个与主体在形态、材料或含义上有明确联系、来自另一种材质或事物类别的异质元素，在一处清晰的交界做嫁接、接续、嵌套或局部替换。选择其中一种关系，把它做具体。让一个元素按构思放大或缩小，维持各片自身的可信结构，让尺度错位成为隐喻。人物保留身份特征或代表性姿态，嫁接优先落在服饰、随身物、头部外轮廓或周边留白。建筑、风景、动植物与静物优先从其结构、地形、走势或材质中寻找可接合的形态。只保留理解这一隐喻所需的图像片段，避免额外装饰和重复主体。

用真实摄影的黑白明暗作为主要结构，让一处取自原照代表性色彩的彩色片段成为对照和视觉落点。彩色片段可落在原照主体或嫁接元素，保持少量而明确，黑白片段保有细腻的灰度和真实材质，不压成死黑剪影。摄影片段精准剪裁，边缘干净，接合处的轴线、遮挡、纹理与光向可辨。可有极薄的印刷叠压感。暖白纸底只呈现低对比、细腻的天然纸纹，颜色克制、表面平整。

拼贴沿下半中央纵轴成组排列，视觉重心收拢，周围留下大面积连续纸白，通常主组约占下半宽度的 30%–48%、高度的 52%–68%，依主体轮廓做小幅调整。上方留一行极细、略疏字距的英文无衬线微字，下方排一行小型英文衬线标题。微字与标题围绕同一视觉轴对齐，以安静的间距、克制的层级与准确的字形体现瑞士极简编辑感。拟写 2–5 个英文词的微字和 1–4 个英文词的标题，根据照片与嫁接关系命名，拼写真实清楚，不遮挡主体，不虚构地点、年代、编号或机构。

整张海报安静、疏离，有当代观念摄影与艺术出版物质感。禁止梦幻发光、重阴影、复杂舞台、拼贴碎屑、撕纸毛边、便签、胶带、贴纸、印章、伪文字、水印、粗糙纸噪、满版背景，以及卡通、矢量或三维渲染。避免随机物件堆叠、等尺度并排陈列、成排的同源横向条带和喧宾夺主的大标题。
```

## 按图应用

- 按原照先选主体和一处场景线索，再确定嫁接对象、相接位置与尺度关系。以缩略图判断：能否认出源照主体，是否看得出它与异质元素的关联。
- 核对黑白主体结构、单处彩色焦点、暖白纸纹、纵向轴线以及上方微字和下方小衬线标题。两处文字都在下半，空白连贯。
