# 日系复古手绘九宫格 `japanese-retro-nine-grid`

## 可直接使用的提示词

```text
将上传照片制成一张 3:4 竖版「日系复古手绘九宫格」双联海报。每张海报只使用一张源照片。画布沿水平中线等分，上下各占 50%，直接衔接。

上半保持原始摄影风貌。保留同一个主体、原有姿态与空间关系，以及照片的质感、光影和色彩。等比适配横幅，裁切时保留关键内容，必要时自然延展原场景背景。所有新增插画与排版集中在下半。

下半在暖白微颗粒纸面中央排列 3 行 3 列小插画，恰好九幅。从同一张照片选取九个彼此有区别的视觉切入点，例如主体轮廓、关键动作、可见物件、局部结构、自然纹理、光影细节和场景意象。保留能让人认出原照的线索。题材简洁的照片可从局部、纹理与明暗关系寻找不同画法，避免九次重复主体、复制整张照片或添加无关物件。

九幅都采用日系复古手绘，用自由轻松的黑色墨线、少量取自原照的平涂色和形状自然的有机色块。保留细微纸粒与手绘边缘，适度改变每幅的尺度、重心和疏密。格距整齐，手绘自然，避免粗重格框、写实描摹、复杂渐变或模板化图标。九格作为整体居中，周围保留宽松的暖白留白。

在九格左右的空白处安排一条从照片主题提炼的简短英文标题，采用细长字形，另一侧配少量微字、细线与简单几何符号。将两侧文字和图形对齐于九格的视觉轴线，留出清楚的阅读空间。采用克制的瑞士编辑版式，避免边栏抢占插画。只输出一张完整海报。
```

## 按照片应用

根据输入拟定九个具体图案，按行列记录每格主题与主要颜色。明确细长英文标题和少量微字，保证图案与文字都能追溯到同一张照片。出图后检查上下画幅、原照保真、恰好 3×3、九格内容区分、墨线与限色手绘质感，以及两侧排版和留白。
