# 圆弧矩阵摄影镶嵌 `arc-grid-photo-inlay`

## 可直接使用的提示词

```text
以这一张上传的原始参考照片为唯一图源，制作一张「圆弧矩阵摄影镶嵌」高级实验艺术双联海报。每张输入独立输出一张严格 3:4 的竖版海报。画面在正中以干净平直的水平接缝分成同宽等高的上下两区，各占总高 50%，两区直接相接。中线只由两区内容自然形成，无描线、间隔、描边、装饰边框或形变。

上半是铺满整个区域的 3:2 横幅摄影，摄影内容从左到右触及边缘。优先按主体和叙事关系等比裁切，先收掉外围空天空、空水面或前景，不裁断主体、关键物件或有叙事意义的倒影。保留原照主体身份和数量、结构、姿态、服饰配饰、物体关系与原有光色。如果满幅裁切会破坏关键关系，仅向左右自然延展原有背景，让环境与原图无缝衔接，原图主体及关键结构继续直接使用。禁止侧边纯色留白、缩图居中、虚化填边、镜像复制、拉伸、扭曲、主体替换、重新调色、重画主体或添加文字。

下半整区使用柔和米白色哑光纸面。用统一尺寸的方格和同规格的四分之一圆弧、圆角拱形构成一组居中的规整矩阵。行列沿统一网格对齐，方格尺寸一致、间距固定，圆弧半径保持统一。允许在格内循序旋转模块形成重复节奏，所有边缘保持利落平整。矩阵大小适中，四周保留宽阔而连贯的米白留白。

矩阵单元采用两种状态。一部分圆弧或拱形作为镂空窗口，透出同一张照片的一幅连续裁景；其余模块使用从原照提取的少量低饱和纯色填充。先为整组窗口统一决定一次取景、比例与定位，再由不同模块边界裁出各自可见的部分。保留能辨认主体的关键局部与前后关系，隔着窗口仍能读出相邻部位的延续。影像只出现在照片窗口内，纯色模块保持平整无渐变，模块之间的米白负形清楚。避免每格重复一张照片、把主体拆成不相干的多个视角，或让照片溢出弧线。

矩阵正下方只排两行居中文字。第一行是简短主标题，使用纤细衬线字、舒展字距和偏大的字号；第二行是更小的宽字距无衬线副标题。两行都从可见主题取词，文字从原照片主色取色并保证可读。文字与矩阵分开留空，不另加编号、微字、边栏或其他装饰。整体保持安静、轻盈的独立艺术杂志版式，让摄影选景、几何节奏和米白留白共同形成收藏级实验艺术印刷质感。纸面仅有轻微、低饱和的印刷肌理。

禁止合并多张素材、自由错位的照片拼贴、装饰卡片、胶带、贴纸、撕边、卷边、画框、褶皱、破损与人为添加的投影；保留照片本身的自然阴影。禁止杂乱背景、额外杂物、手绘笔触、过量噪点、畸形几何、模糊发虚、色彩溢出、文字错乱和水印。只输出一张完成的海报。
```

## 按图应用

- 优先以保留视觉关系的等比裁切做满上半。需要延展时只补原有环境并检查接缝。下半另为所有照片窗口确定一幅连续裁景，让窗口分布保留关键辨识线索。
- 根据原照选主色、主标题和副标题。矩阵行列随主体取景决定，同一张海报内统一单元尺寸、间距与圆弧半径。
- 核对居中直缝、上半摄影满版、主体关系与原有色彩、下半圆弧矩阵的两种模块状态、照片片段的同源连续性，以及矩阵下方居中两行文字。
