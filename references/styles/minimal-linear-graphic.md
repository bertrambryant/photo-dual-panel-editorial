# 极简线条视觉归纳 `minimal-linear-graphic`

## 可直接使用的提示词

```text
以上传照片为唯一内容图源，每张照片单独制作一张 3:4 竖版「极简线条视觉归纳」海报。上下同宽、严格等高，各占画面 50%，沿正中央水平直接衔接。不做多图拼接，不加间隙、分隔线或外框，只输出一张完整海报。

上半满版保留原照的主体身份、数量、结构、比例、姿态、真实材质、自然光影与色彩氛围。仅做轻微、克制的摄影调色，保留艺术杂志与展览图像质感。按画幅等比取景，需要时只沿原环境自然延展外围背景，不拉伸、扭曲或重绘主体。上半无文字。原照中的可读文字只在其所在表面局部清理，保留招牌、路牌或其他承载物的形体、材质与光影。

下半将同一照片做成带工程图纸秩序的线条平面设计，保留主体比例、方位、动作和空间关系。从照片中提取关键轮廓和接合点、定下视角和纵深的轴线，以及一至三个记忆点。决定构图主轴与对齐基线，让标题、线图和标注依托同一版式规则。主体结构线纤细但明确，次级构造线更细，定位网格、投影线和引线最浅，可用实虚变化区分层级。选取最能说明造型的局部展开细节，例如拱跨的节奏、构件沿曲面的收缩、器物的对位。把较密的构造信息集中在关键位置，外围和标题周围保留连贯留白。

下半应看得出主动安排的图纸信息层，而不止一组轮廓。按同源结构安排少量可见轴线、坐标网格、投影引线、刻度或编号，任选能说明关系的形式，辅以一至三处克制的抽象块面，标出光区、材料差异或结构分区。标记贴近所指要素并与版式对齐，标注线不穿过标题，不把整幅铺成同密度的网格。图内编号或局部坐标只用于当前画面索引，不冒充实地坐标或实测尺寸。通过线重、实虚、块面与空白组织阅读顺序，保留平面海报的辨识度。

下半左上保留一处复古打字机式等宽小标题，字重和尺度克制。可另加少量清晰的图内索引，文字弱于图形。标题从画面可见的主体、环境或情绪提炼，优先用短词。地名、日期、街道名、实际尺寸和地理坐标须来自可核对的原照或用户提供的资料，无依据时省略。保留原照招牌或路牌时只准确转写清晰可辨的字符，其余保留承载物形体。所有实际出现的字必须清楚、正确，避免伪文字。

从主题的气候、光线、材质、历史感和情绪取色。根据照片采用单色、双色或少量克制配色，线图、坐标辅助层和色块清楚分层。整体细节丰富、秩序清晰，保持现代编辑版式、连续留白和收藏级旅行、城市品牌或文化主题海报质感。避免只画轮廓、逐边描摹、满幅密网、过重排线、标注堆叠、无意义尺寸、过大色块、模板渐变、夸张大标题和水印。
```

## 按图应用

- 先确定对齐规则，再按题材挑选有解释力的标注。建筑可突出跨距与立柱或楼层关系，曲面可突出连续轮廓、分区和局部网格变化，人物或器物可用定位线说明姿态、部件和彼此关系。图内坐标作为版式索引使用。
- 至少读得出主体结构、次级构造和辅助定位三层线条。将细部集中在有信息的区域，用少量色块承托结构，给标题和图形四周保留整块空白。
- 小标题固定在下半左上，采用复古打字机式字形。放大核对编号、招牌和其他文字，缩小查看时应先看到主体结构，再读到辅助结构和标注。
- 核对两区严格等高、上半无字、同源关系保留。若只剩几根示意轮廓，补足有解释力的辅助层；若辅助层压过主体，则减少标注或调浅线重。
