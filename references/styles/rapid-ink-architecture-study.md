# 疾线建筑观察 `rapid-ink-architecture-study`

## 可直接使用的提示词

```text
把每一张上传的建筑或旅行照片各制作成一张独立的「疾线建筑观察」编辑海报。一张成品只使用对应的这一张原照。画布严格为 3:4 竖版，上下各占高度 50%，在正中平直相接，无间隙、白线、画框或装饰边。

上半从原照等比取景，以原片满幅展示，优先保留建筑身份、层数、体量比例、机位、透视、自然光影，以及人物、道路、水岸等与主体的空间关系。只做轻微艺术出版物调色和极薄胶片颗粒。优先裁去无关外围空间，必要时只自然延展真实背景。不得拉伸、移动、重绘或替换摄影主体，不添加排版文字。

下半以温暖天然米白速写纸满铺，用碳黑墨重组同一张照片中的建筑，画成一幅有完整结构的现场观察。自最高的可见结构画到主体落地处，或画到原照中可见的支撑与遮挡边界。先立清楚主轴、外轮廓、屋顶或塔尖、开口节奏和前后层次，再选二至四组真实可见的次级构件深入刻画，例如拱券厚度与拱脚、窗洞与窗楣、柱头柱身和柱基、层叠屋檐、扶手与踏面。让关键构件沿同一透视和空间方向相连，可沿原照保留一至三条必要的道路、桥梁、水岸、地面或栏杆线。省去无助于辨识的外围景物，只画原图支持的结构与细节。

用黑色钢笔、细针管笔和少量干涩毛笔尖绘制。较重的主线立住体量，细线刻画构件、接缝与重复节奏。局部用短密排线和交叉排线压住结构交界、内凹开口及阴面；以笔压、叠线、断墨和纸白区分材质、前后与受光。线条在部分边缘及次要景物自然停笔，留回找的重线、轻微手抖、短断墨与越线。保持重点构件完整，避免大块阴影填满、均匀排线和机械描边。下半只用米白纸和碳黑墨。

建筑速写约占下半区宽度 60%–72%、高度 75%–90%，可偏向一侧，保留至少约 40% 连片纸白。文字独立布置在连续留白处，与速写之间有清楚间隔。只排一个 1–3 个英文单词的主标题、固定字段「INK NOTE 01」和一句 5–10 个英文单词的具体现场观察。标题和观察来自照片可见内容，有依据才写地名或年代。使用略有吸墨感的窄体铅字或朴素手写体，按需加一条短墨线。标题在正常预览尺寸下须清楚可读，辅助字拼写准确。

整体像建筑师在现场沿着透视寻找结构、挑关键位置画深的一页观察稿。避免照片描边滤镜、CAD 制图、均匀精密排线、同构图临摹、完整背景、灰洗、水彩、彩色线条、数字羽化、柔焦、满页密线、额外文案、作者名、签名、Logo、二维码及水印。只输出一张完成的 3:4 竖版海报。
```

## 按图应用

- 出图前列出主体的最高点、支撑或可见边界，再选二至四组次级构件和一至三条必要的场地方向线，确定前后层次和局部重墨的位置。
- 检查主要构件能否从顶端连贯读到底部，浓墨是否集中在有结构意义的节点，外围是否自然停笔。正常预览尺寸下核对文字和连片纸白。
