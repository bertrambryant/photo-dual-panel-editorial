# 针式连续纸横幅 `dot-matrix-banner`

## 可直接使用的提示词

```text
将每张上传图像独立制作成一张 3:4 竖版「针式连续纸横幅」海报。每张海报只使用一张源图。沿水平中线严格等分，上下各占 50%，两区满版直接相接。中线保持干净，无隔条、边框、额外画格或标签。所有风格化处理和纸张肌理都集中在下半。

上半复用原图。若输入为照片，保留主体身份、数量、结构、姿态、朝向、真实质感、自然光影和原有色彩氛围。只做轻微摄影调色，呈现独立出版物的摄影质感。等比适配横幅，必要时自然延展同一环境，避免拉伸、扭曲、镜像或改变主体。若输入本身是插画，上半按原样保留其画法、颜色和主体。

下半在暖白或浅灰桌面上放一条微黄的老式针式打印机连续纸。纸带两侧都有成排等距圆形齿孔，页与页之间有细虚线撕缝或折痕。让纸带沿页间自然折叠、斜放或局部垂落，体现纸的纤维、折脊起伏、孔洞边缘和落在桌面上的柔和投影。纸带组合约占下半画面宽度的 50%–60%，下半至少留出 45% 空白。让关键图案与标语在折痕之间清晰可读。

用同一张输入图提炼一个可辨认的主体简图，以针式字符或圆点组成图像。人物保留数量、姿态、朝向、发型和服装的大明暗分区，省略五官细节；动物保留物种特征、关键花纹和姿态；建筑保留屋顶走势、主要入口和体量比例；交通工具保留朝向、车轮或船身弧线；风景保留一条关键的地平线、山脊或岸线。省去密集植被、重复窗格、杂乱背景和广告招牌。用点阵的疏密表达明暗与体量，让规则的针脚网格清楚可见。

在同一条连续纸上印一行醒目的点阵大字横幅。依据原图的情绪或事件写一句可读标语，语种自由，像为一个普通瞬间专门打印的庆祝横幅。页边只印一个极小的打印编号。简图和大字主要用黑色或深蓝色带墨，保留浓淡不一、偶有一行偏浅或轻微错行的印迹。再从源图抽取一种颜色，只给一个小元素着色，例如一颗星、一个字母或简图的一处小细节。其余维持克制的色带墨色。

输出一张完整海报。让连续纸、齿孔和折痕体现针式打印的物理过程，点阵图像与横幅大字形成主次。避免整幅数码点阵滤镜、满版文字、假复古素材、霓虹色、3D 渲染与模板化排版。
```

## 按照片应用

先判断源图是摄影还是插画，再选出最少的主体识别线索、适合该瞬间的一行标语、页边编号和唯一彩色点。根据标语长度安排连续纸的折叠，让主体简图和文字都能读清。出图后核对等高分区、上半原图、纸带连续性、两侧齿孔、页间撕缝、印迹网格及留白。
