# 伪彩热成像渐变扫描 `false-color-thermal-scan`

## 可直接使用的提示词

```text
以上传的图片为唯一来源，制作一张 3:4 竖版「伪彩热成像渐变扫描」海报。每张源图单独输出一张。沿水平中线严格等分，上下各占总高度 50%，直接衔接，无间隔、分割线、画框或多图拼贴。

上半满版保留原照的主体身份、结构、比例、姿态、真实质感、自然光影与原有色彩氛围。仅允许轻微摄影调色，保持艺术杂志和展览摄影质感。优先等比适配，裁切仅限外围冗余内容，必要时自然延展原有背景。禁止拉伸、扭曲、重绘或替换主体。上半无可读文字。原照已有可读字形时，仅在原位用相邻材质淡化字形，保留其承载物的结构与质感。

下半为高对比的伪彩热成像，以纯黑为底。提炼原照最有辨识力的轮廓走势、姿态或空间关系，用一组连续流动的色温区域呈现主体。热区重心居中偏下，纵向跨度约占下半区高度的四分之三，从上向下延展并局部向侧面斜伸。局部末端可自然触边或裁出画幅，热区整体仍然集中。保留宽阔的黑色周边、不规则深黑内凹和少量断续留空。形态由少量大尺度、平滑、圆钝的曲线构成，保留一两处识别主形所需的转折或负形，删除细碎结构和重复刻画。

采用固定的伪彩分布。大块青蓝与蓝绿色集中在冷色内部，沿主体轮廓和内部区域缓慢过渡到黄绿、明黄，再在外围形成橙红、深红的热晕。只在局部让红色轻微向纯黑空域渗出。颜色承担温度层次与发光边界，保持冷色内核、暖色外圈与纯黑负形的高对比。用连续渐变、低频软边、轻微失焦和柔焦泛光组织色层，禁止整块平涂、黑描边、轮廓线、尖刺锯齿、真实光源投影或光束。

只保留轻微数字传感器噪声和低分辨率热成像颗粒，颗粒不得盖过渐变。左上可省略文字，或排一至两行低对比、稀疏的等宽小字，例如“SCAN 01”，仅作界面点缀。不得出现主标题、实测温度、温标、边框、十字标或其他界面图形。下半禁止自然固有色、真实材质、摄影锐度、密集线稿、立体阴影、金属反光、三维建模、纸纤维、胶片颗粒、复古旧化、卡通填色、满版发光背景和额外装饰。只输出一张成品海报。
```

## 按图应用

- 从源图选择少量能辨识主题的轮廓转折、姿态或空间关系。把热区组织成一组连续的纵向形体，局部侧伸与深黑留空沿原形方向安排。
- 冷内核与暖外缘是固定伪彩关系。渐变主要附着在主体轮廓与内部区域，周围保留纯黑，热晕仅在局部向黑域软化。
- 检查上半摄影及无字要求，下半热区高度、斜向动势、冷暖分布和黑色空域。若使用技术小字，只放下半左上角，可用样式化扫描序号，避免给出测量数据。
