# 日式轻墨留白漫画 `japanese-light-ink-manga`

## 可直接使用的提示词

```text
以每张真实照片为唯一内容来源，各制作一张 3:4 竖版上下对照海报。沿水平中线分为两个同宽、等高的区域，各占画面高度的 50%，直接衔接，无间隔、无边框、无叠压。所有主体及物件关系均来自上传照片。

上半直接使用原照片，保留原色、光影与摄影质感，不重绘、不调色、不加文字。等比缩放，优先只裁去外围背景。若裁成横幅会截断主体、关键动作或物件关系，则等比容纳所需画面，以浅灰米白补足空余区域，不拉伸、不补画内容。

下半将同一画面转绘为日式手绘漫画，保留原照的情绪、受光方向和主要明暗关系。人物保留脸型、发型外轮廓、神态、动作与服装类别，用简洁漫画面形和成束头发表现。动物保留物种、体态和毛色分区。物品保留外轮廓和关键结构。风景将主要地形、建筑及前后层次一起转绘。按照照片中实际可见的范围画出接触与遮挡，不补全被遮住的部分，不新增主体或道具。

用轻薄墨黑线勾形，落笔、转折与收笔带有轻微提按、顿挫与不齐，内部仅保留说明结构的线条。用少量连续、干净、不透明的平涂色块铺色，将阴影归并为少量硬边色面。保留主体固有色与辨识色；浅灰米白纸上以暖红为主强调，只在小范围辅以灰蓝，红多蓝少。避免逐根刻画毛发、密集排线和写实纹理。

把主体和辨识场景所需的环境作为一个整体，保持原有比例，缩小后居中。组合以占下半宽约 65%–70%、高约 60%–65% 为参考；遇到细长或宽阔的构图，优先把整体等比放入这个范围，另一方向自然多留空白。四周露出明显且连贯的浅灰米白纸面。背景只保留理解场景与空间所需的元素；风景画保住主要景观的整体关系。插画不贴边、不铺满，不用色块填空，不加插画边框。
```

## 按照片应用

按实际题材把辨识特征、接触点、主要光向与必要环境写进同一份提示词。上半若因主体完整性需要补边，只在原片外补纯色。下半默认无新增文字；交付时以主体和环境组合的外接范围核对占幅。
